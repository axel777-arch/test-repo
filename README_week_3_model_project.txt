WEEK 3 MODEL PROJECT\n\nKeep the HTML, CSS and JS files in the same folder, then open week_3_model_project.html in a browser. Try the theme toggle, greeting button, learning-goal form, checkboxes and contact-form demo.\n\nWhat it demonstrates:\nHTML: semantic header/nav/main/section/article/footer, headings, links, lists, forms, labels, input types, metadata and accessibility attributes.\nCSS: selectors, cascade, custom properties, box sizing, spacing, Flexbox, Grid, focus/hover states, responsive media queries and theme variables.\nJavaScript: const/let, conditions, functions, DOM selection, textContent, classList, createElement, events, form submission, preventDefault and event delegation.\nGit: use git status, git add, git commit and git push to track changes.\n\nThe contact form is a front-end demonstration. It validates in the browser but does not send email or store data.\n
